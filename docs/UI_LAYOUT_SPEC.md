## C. 综合对比

### C1 行业共识

| 参数 | 共识值 | 依据产品数 |
|---|---|---|
| 首屏布局 | 左侧栏 + 中间欢迎语 + 输入框，无右侧常驻面板 | 6 [估] |
| 侧栏宽度 | 264–269pt（截图）；估值 240–288px | 2 [截图] + 4 [估] |
| 列表项高 / 字号 | 32–36px / 13–14px | 6 [估] |
| 消息区与输入框最大宽度 | 约 768px，两者同宽 | 5 [估] |
| 消息对齐 | 用户右对齐气泡，助手左对齐无气泡 | 6 [估] |
| 输入框结构 | 上行文本域，下行工具条；附件在左下 | 6（ZCode 左下 [官方]） |
| 模型选择器位置 | 输入框右下，与发送相邻 | 4（ZCode [官方]） |
| 权限控制 | 输入框内下拉，默认需确认 | 3 [官方]：Codex、ZCode、Cowork |
| 输入框圆角 | 约 14pt（截图两款一致）；估值 12–24px | 2 [截图] + 4 [估] |
| 欢迎语 | 输入框上方居中，约 28–30pt / 700 | 2 [截图] + 4 [估] |
| 首屏可交互数 | 12–33；截图两款 33、30，其余 4 款估 12–15；平均 (33+12+30+14+15+13)/6 = 19.5 | 2 [截图] + 4 [估] |

### C2 差异化点

| 维度 | 各产品做法 |
|---|---|
| 权限档位 | Codex 3 档；ZCode 4 档含 Plan；Cowork 2 档（Manual/Auto）；Manus、Kimi Work 逐条询问无常驻开关；WorkBuddy 输入框内切 Ask/Craft/Plan |
| 模式切换 | Cowork 在输入框切 Chat/Cowork；WorkBuddy 切 Ask/Craft/Plan；ZCode 用 Shift+Tab 循环 |
| 模型选择 | ZCode 模型名旁加思考档；Codex 按登录身份过滤；Manus 未见用户选模型 |
| 执行过程 | Manus 右侧面板实时展示；ZCode 右侧面板放浏览器与旁支对话；Codex、Cowork 以消息流内联为主 |
| 上下文入口 | ZCode 用 @ 文件、# 历史会话、/ 命令、$ 技能；Kimi Work 以本地工作目录为入口 |
